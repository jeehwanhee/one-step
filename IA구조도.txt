  [ 인증 영역 ]  (최초 가입 시 1회만 진행)
================================================================

┌─────────────────────────────────────────────────────────────┐
│  AuthScreen  (로그인 화면)                                    │
│                                                             │
│  · Google 계정으로 로그인 버튼                                │
│  · Firebase Authentication + Google OAuth 2.0 처리          │
└────────────────────────┬────────────────────────────────────┘
                         │ 신규 사용자
                         ▼
┌─────────────────────────────────────────────────────────────┐
│  SignupScreen  (회원가입 화면)                                 │
│                                                             │
│  · 닉네임 입력                                               │
│  · 나이 선택                                                 │
│  · 이용약관 동의 체크       → (Notion 링크 연결)              │
│  · 개인정보 처리방침 동의    → (Notion 링크 연결)              │
│  · 모두 입력/동의 시 완료 버튼 활성화                          │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│  InitQuestionScreen  (초기 고립도 측정)                        │
│                                                             │
│  · 6개 문항 순차 응답 (페이지 형태)                           │
│    1) 함께 사는 가족/동거인 수                                │
│    2) 최근 일주일 식사 형태                                   │
│    3) 평균 수면 시간                                         │
│    4) 하루 외출 빈도                                         │
│    5) 히키코모리 자가진단                                     │
│    6) 주요 활동 시간대                                       │
│  · 응답 기반으로 고립도(0~100) 산출 → Firestore 저장          │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
                    [ 메인 영역 ]


================================================================
  [ 메인 영역 ]
================================================================

┌─────────────────────────────────────────────────────────────┐
│  MainScreen  (메인 화면)                                      │
│                                                             │
│  · 픽셀아트 파크 배경 (Canvas 직접 렌더링)                     │
│    ├─ 하늘: 티어별 색상, 구름·태양 (티어3+)                   │
│    ├─ 지상: 잔디 3겹 레이어                                   │
│    └─ 장식: 나무(1+) 울타리(2+) 연못(4+) 꽃(5+)             │
│  · 티어별 픽셀아트 동물 배치 (최대 8마리)                      │
│    ├─ 앞줄: 병아리(좌) / 곰(중) / 강아지(우)                  │
│    ├─ 중간: 말(좌) / 거북이(우)                               │
│    ├─ 뒷줄: 고양이(중앙왼쪽)                                  │
│    └─ 하늘: 돌고래(좌) / 파랑새(우)                           │
│  · 진행 중 퀘스트 카드 (있을 경우 화면 상단 표시)               │
│  · 하단 버튼 3개                                             │
│    ├─ [퀘스트 받기] → ReceiveQuestScreen                     │
│    ├─ [컬렉션]     → CollectionScreen (스와이프 전환)         │
│    └─ [설정]       → SettingScreen                          │
└───────┬─────────────┬──────────────┬────────────────────────┘
        │             │              │
        ▼             ▼              ▼
  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │ 퀘스트    │  │ 컬렉션    │  │  설정    │
  │  영역    │  │  영역    │  │  영역    │
  └──────────┘  └──────────┘  └──────────┘


================================================================
  [ 퀘스트 영역 ]
================================================================

┌─────────────────────────────────────────────────────────────┐
│  ReceiveQuestScreen  (퀘스트 받기)                            │
│                                                             │
│  · 현재 기분 선택 (5단계 버튼)                                │
│    매우 나쁨 / 나쁨 / 보통 / 좋음 / 매우 좋음                 │
│  · [퀘스트 받기] 버튼 누르면 AI 추천 시작                     │
│    ├─ LocationHelper → 현재 위치 지역명 확인                  │
│    ├─ 서울 실시간 도시데이터 API → 날씨·혼잡도 조회            │
│    ├─ Model_B → 고립도·기분 기반 적정 난이도 예측              │
│    ├─ Firestore → 난이도 비율로 퀘스트 20개 샘플링             │
│    └─ Gemini API → 환경 조건 반영해 최종 8개 선별             │
│  · 추천 퀘스트 8개 목록 표시                                  │
│  · 퀘스트 선택 → 시작 확인                                    │
└────────────────────────┬────────────────────────────────────┘
                         │ 퀘스트 선택
                         ▼
┌─────────────────────────────────────────────────────────────┐
│  MainQuestScreen  (퀘스트 수행 화면)                           │
│                                                             │
│  · 선택한 퀘스트 내용 표시                                    │
│  · [완료] 버튼                                               │
│    ├─ progress(경험치) 누적                                   │
│    ├─ difficultyQueue / questResultsQueue 갱신               │
│    ├─ 티어 승급 조건 확인 → 자동 승급                         │
│    ├─ prevQuests에 이력 저장                                  │
│    └─ Firestore 업데이트 후 메인으로 복귀                     │
│  · [포기] 버튼 → 실패 처리 후 메인으로 복귀                   │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
                    [ MainScreen ]


================================================================
  [ 컬렉션 영역 ]
================================================================

┌─────────────────────────────────────────────────────────────┐
│  CollectionScreen  (동물 컬렉션)                              │
│                                                             │
│  · 우측에서 좌로 스와이프 제스처로 진입 (또는 버튼)            │
│  · 상단 헤더                                                 │
│    ├─ 현재 티어 표시                                         │
│    └─ 다음 티어까지 경험치 진척 바 (LinearProgressIndicator) │
│  · 동물 도감 그리드 (3열)                                    │
│    ├─ 해금됨: 픽셀아트 동물 + 이름 표시                       │
│    └─ 미해금: 자물쇠 아이콘(🔒) + ??? 표시                   │
│  · 완료한 퀘스트 이력 목록                                    │
│    └─ 날짜 / 퀘스트 이름 / 난이도                            │
│  · 좌로 스와이프 → 메인 화면으로 복귀                         │
└─────────────────────────────────────────────────────────────┘


================================================================
  [ 설정 영역 ]
================================================================

┌─────────────────────────────────────────────────────────────┐
│  SettingScreen  (설정)                                        │
│                                                             │
│  · 이용약관 및 개인정보 처리방침  → Notion 페이지 외부 링크    │
│  · 로그아웃                       → InitScreen으로 이동      │
│  · 회원탈퇴                                                  │
│    ├─ 확인 다이얼로그 표시                                    │
│    ├─ Firestore 사용자 데이터 삭제                            │
│    ├─ Firebase Auth 계정 삭제                                │
│    └─ InitScreen으로 이동                                    │
└─────────────────────────────────────────────────────────────┘


================================================================
  [ 전체 화면 전환 흐름 요약 ]

    │                                                    │

                                                         ▼
                                                    MainScreen
                                               ┌────────┼────────┐
                                               ▼        ▼        ▼
                                        Receive      Collection  Setting
                                        QuestScreen  Screen      Screen
                                               │
                                               ▼
                                        MainQuestScreen
                                               │
                                               ▼
                                          MainScreen


================================================================
  [ 데이터 흐름 요약 ]
================================================================

  사용자 입력 (기분·퀘스트 선택)
       │
       ▼
  ViewModel (StateFlow)
       │
       ├──▶ LocationHelper ──▶ GPS → 서울 지역명
       │
       ├──▶ 서울 실시간 도시데이터 API (날씨·혼잡도)
       │
       ├──▶ Model_B ML 모델 (난이도 예측)
       │
       ├──▶ Firebase Firestore (퀘스트 DB 조회)
       │
       └──▶ Google Gemini API (최종 8개 선별)
                                    │
                                    ▼
                          UI (Composable 화면 갱신)
                                    │
                                    ▼
                          Firebase Firestore (결과 저장)
