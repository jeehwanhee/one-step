# 한걸음 (oneStep)

> 은둔·고립 청년을 위한, 단계적 사회 복귀 퀘스트 Android 앱

> 2026 서울시 빅데이터 활용 창업 대회 출품작

- '쉬었음 청년' 44.6만 명(2024, 역대 최대), 고립 청년 추산 54만 명. 

- 기존 복지 서비스는 결국 기관 방문, 대면 상담으로 귀결 
---
- '한걸음'은 자체 학습시킨 AI 모델로 사용자의 고립도를 측정하고, 기분·날씨·주변 장소 등 실시간 데이터를 반영해 그날 수행 가능한 난이도의 퀘스트를 사람과의 접촉 없이 앱 안에서 제시

- 퀘스트를 완료하며 경험치를 쌓고 티어를 올려 픽셀 동물을 모으는 게임형 구조

---

## 주요 기능

- **초기 고립도 측정** — 서울시 고립은둔청년 실태조사 기반 AI 모델(`Model_A`)이 설문 8문항으로 고립도(0~100)를 산출, 퀘스트 9개 완료마다 자동 재측정(설정에서 수동 재측정 가능)
- **맞춤 퀘스트 추천** — 기분·이전 성공/포기 이력·티어를 반영한 AI 모델(`Model_B`)이 난이도(1.0~5.0)를 산정하고, 날씨·위치를 고려해 Gemini가 오늘의 퀘스트 8개를 선별
- **위치 기반 퀘스트 치환** — "{공원}에서 산책하기" 같은 템플릿 퀘스트를 GPS 기준 반경 내 실제 공원·도서관 이름으로 치환해 장소 선택의 부담 제거
- **단계적 보상** — 경험치 → 티어 상승 → 픽셀 동물(병아리~돌고래) 획득, 도감/메인화면 반영 및 동물과의 상호작용
- **회고 / 통계** — 퀘스트 완료 시 검증질문 답변으로 회고 기록, 고립도 변화 추이 시각화
- **알림** — 미접속 2·5·10·20·30일차에만 보내는 안부 알림 (독촉 없음, 설정에서 끄기 가능)

---

## 설계 원칙

- **공개 비교 없음** — 랭킹·이용자 간 비교 기능을 두지 않고, 진척도는 본인 화면에서만 보여줍니다. 사용자 문서는 본인 것만 읽고 씁니다.
- **독촉하지 않는 알림** — 알림은 미접속 2·5·10·20·30일차에만 보내는 안부 형태이며, 퀘스트·보상·기간을 언급하지 않고 설정에서 끌 수 있습니다.
- **미접속·장기 이용은 실패가 아님** — 실패 기록은 사용자가 직접 포기한 경우에만 남고, 미접속은 기록하지 않습니다. 체류 기간·상호작용 지표는 추가할 예정입니다.

| 축 | 현재 기능 | 예정 |
|---|---|---|
| 자율성 | 제안된 퀘스트 넘기기·수락, 알림 끄기 | 난이도 직접 선택 |
| 관계성 | 픽셀 동물과의 상호작용 (사람과의 접촉 없음) | 익명 응원 |
| 유능감 | 경험치·티어·도감, 회고 기록, 회복도 그래프 | 체류 기간·상호작용 지표 |
| 선의 | 아직 없음 | 남을 돕는 유형의 퀘스트 |

| [`scripts/`](./scripts) | Firestore 데이터 업로드, AI 모델(Model_A) 재학습 | Python |

---

## 기술 스택

**Client** : Kotlin, Jetpack Compose  
**Infra** : Firebase Auth, Firebase Firestore  
**AI/ML** : XGBoost(Model_A·B 학습) → m2cgen으로 Java 코드 변환, Gemini API(퀘스트 선별·문장 생성)  
**외부 데이터** : 서울 열린데이터광장, 기상청 단기예보  
**Data 준비** : Python(firebase-admin, pandas, xgboost, m2cgen)

---

## AI 파이프라인

1. 초기 설문 8문항 → `Model_A`(XGBoost) → 고립도 0~100 산출 → Firestore 저장
2. 퀘스트 요청 시 현재 기분 + 최근 성공률·난이도·티어 → `Model_B`(XGBoost)가 적정 난이도(1.0~5.0) 산정
   - 이전 성공 ≤3회면 고립도를 반영해 난이도 하향, ≥9회+기분≥4면 상향, 그 외엔 소폭 조정
   - 티어별 최대 난이도 상한 적용(Tier0 1.5 ~ Tier6·7 5.0), 기분 ≤2면 난이도 추가 상승 차단
3. 산정된 난이도 기준으로 Firestore 퀘스트 중 후보 20개 무작위 추출
4. 사용자 위치를 격자좌표로 변환해 기상청 API로 날씨(기온·강수형태) 조회
5. 후보 퀘스트 20개 + 날씨 데이터를 Gemini에 전달 → 오늘 상황에 맞는 8개를 퀘스트 ID 배열로 응답 (실패 시 20개 중 랜덤 8개로 대체)
6. 응답받은 퀘스트에 `{장소}` 템플릿이 있으면 GPS 반경 내 실제 공원·도서관 이름으로 치환
7. 완료 시 경험치 적립 → 티어 상승 → 픽셀 동물 획득, 검증질문 답변은 회고 기록으로 저장
